# Solana Swap & Staking

Proyek ini adalah platform Swap dan Staking untuk token di Solana, menggunakan Next.js untuk frontend dan integrasi dengan Serum DEX/Jupiter API.

## Fitur
- Swap token di Solana tanpa smart contract sendiri.
- Staking token dengan smart contract open-source.
- Gratis di-host di Vercel.
